// 02. GUIDE

HOW TO JOIN

01

INSTALL FIVEM & GTA V

PC版GTA VとFiveMクライアントを事前準備します。

02

JOIN DISCORD SERVER

公式Discordに参加し、ルール同意およびホワイトリスト認証を完了させます。

03

CONNECT TO SERVER

AVALON PVから、もしくはFiveMより `AVALON PV` を検索し参戦！

04

SELECT YOUR FACTION

所属する勢力（EAST SIDE または WEST SIDE）を選択し、チームに貢献します。
